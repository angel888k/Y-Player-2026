# M28P11 快进 / 快退的等待 · 搜索收口 · 横向排布两块问题

- 状态：**已改**（本地闸门全绿 + 新用例）；上机观感等用户确认
- 时间：2026-10-12
- 触发：用户报「快退或者快进视频的加载速度慢；搜索影视的速度还是慢；设置里展示方式改成横向排布，
  图例里那一块（分类条 + 筛选行）应该不显示，横向排布站点加载不出来、一直加载中」。

## 一、快进 / 快退慢：系统内核一直用「精确到帧」的 seek

`SystemPlayerEngine.seekAsync` 用的是 `toleranceBefore/After = .zero` —— AVFoundation 必须从上一个
同步帧一路解到那一刻：长 GOP / 高码率片子上就是「按了快进，画面半天不动」。
另外两个内核本来就没这毛病（mpv `seek absolute` 默认落在关键帧；自研内核的 seek 丢给解码线程异步做）。

改：容差 ±0.5 秒（`SystemPlayerEngine.seekTolerance`）。这与参考实现（ExoPlayer 的
`SeekParameters.CLOSEST_SYNC`）是同一类取舍：落点差半秒看不出来，但少解小半个 GOP —— AVFoundation
官方也是「给容差换响应」的口径。

## 二、搜索还是慢：补搜轮没有上限（实测数据）

**在本机用真 bundle 实测**（`Tools/out/search-timing3.txt`，node 直跑宿主、并发 12 站、关键词「哪吒」）：

| 站点 | 用时 | 结果 |
| --- | --- | --- |
| 蜡笔 / 花卷 / 闪电 | 0.7–1.0s | 各 10 / 7 / 4 条命中 |
| 立播 | 1.6s | 2 条 |
| 观影 | 4.4s | 13 条 |
| 玩偶 / 七味 | ~1s | 403（这俩拒绝） |
| 快映 / 虎斑 | 1.9s / 15s | ECONNRESET |
| 木偶 / 多多 | >45s | 悬着不返回 |

而配置里**标了 `indexs`（参与聚合搜索）的只有 2 个**：「豆瓣|首页」「日期:20261010」——
对任意关键词都是**几毫秒返回空列表**。于是每次搜索的实际路径是：
首轮 2 个（秒回、零命中）→ 补搜轮把剩下 **94 个站点全扫一遍**（M28P9 只把它分成了波，没有上限）
——界面上的「搜索中」要挂到整轮扫完（分钟级）。这才是「还是慢」的真身。

改（`AggregateSearchRules` + `runSearch` 的补搜轮）：

- 补搜轮最多 `fallbackWaveLimit = 3` 波（每波 `firstRoundLimit = 12` 个站点）；
- 墙上够 `enoughHitSites = 3` 个站点命中就收手（这面墙是「挑入口」用的，不是把 96 个站点全扫一遍）；
- 判定抽成纯函数 `shouldContinueFallback(hitSiteCount:wavesSearched:remainingSites:)` + 用例。

## 三、横向排布：那一块不该显示 + 「一直加载中」

1. **分类条 / 筛选行只属于纵向展示**（用户口径 + 参考图）：横向展示是按分类分区的那一套，
   顶上不摆这两块。`scrollBody` 里那两块现在包在 `model.homeLayout == .vertical` 里。
2. **「一直加载中」的真因**：`loadSections()` 借用了**共享的加载代次**（`beginDiscoverLoad()`）——
   而那个号会被「首屏加载 / 换分类 / 刷新首页」随手推走：推走之后这一轮的分区内容写不进去，
   而 `isLoadingSections` 卡在 `true` 上（`defer` 里那句要过代次检查才复位）→ 界面永远「加载中…」。
   现在改成用 `sectionLoadKey`（站点 + 接口版本，`.task(id:)` 用的同一个键）当**上下文号**核对，
   加载态**无条件**收尾；键变了那边 `.task` 自己会重跑（跨文件引用 `sectionLoadKey`，它不再带 `private`）。

## 四、验证点

1. `swift test --package-path Packages/CatVodUI`（新增补搜轮边界用例）、
   `swift test --package-path Packages/CatVodPlayer`（系统内核改动，原有 seek 相关用例兜着）；
2. 上机：
   - 系统内核播放中双击 / 拖进度条快进快退：应当「按了就走」，不再等按秒计；
   - 搜索一个新词：首波结果 1~2 秒内出现；整体「搜索中」不超过约 3 波（不再挂着分钟级）；
   - 设置 → 展示方式改「横向排布」：顶上不再有分类条 / 筛选行；分区列表应当正常出内容（不再一直加载中）。
