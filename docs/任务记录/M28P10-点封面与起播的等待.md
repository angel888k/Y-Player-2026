# M28P10 点封面 / 起播的等待 · 换集从头播

- 状态：**已改**（本地闸门全绿 + 两条新用例）；上机观感等用户确认
- 时间：2026-10-12
- 触发：用户报「1. 点击封面后的加载速度有点慢；2. 选集播放或者下一集播放应该是从头播放；
  3. 播放视频前的加载速度有点慢」。

## 一、点击封面慢：js2p 站点的详情一直没进缓存（#1）

`DetailCache.shouldCache` 原来是「只有 CMS（type 0/1/2/4）能缓存，type=3 一律直连」——
而主接口（kstore 那类）实测 **96 个站点里 95 个是 js2p（type=3）**：等于每次点封面都重打一次宿主，
返回再进也是（用户报的「点封面后的加载速度有点慢」）。

**复核当初那条挡板的理由**（「详情可能带会话态地址」）：对 js2p 不成立 ——
这类站点的**播放地址是播放时现换的**（`PlayRequestBuilder` 给 `.spider` → `SitePlayEpisodeView` 走
`POST /play`），详情里只有线路 / 选集（集 id 是站点路径，不是会过期的直链），缓存不会让播放拿到
失效地址；换接口 / 宿主重启时 `load()` / `refreshHost()` 都会 `detailCache.invalidateAll()`
（本地端口变了也一并作废）。

改：`shouldCache = site.kind != .spider || site.isCatSpiderHTTP`（JAR / Python / 设置类仍不缓存）。
新增用例「js2p 站点也缓存：第二次进详情不再打宿主」。

## 二、起播慢：字幕下载挡在起播前面（#3）

三处调用点都在**构造播放资源之前** `await model.loadSubtitles(...)` —— 而 `loadSubtitles` 是网络活
（按站点给的 `subs` 去下字幕文件）：

| 调用点 | 挡在谁前面 |
| --- | --- |
| `SitePlayEpisodeView.loadResource()` | 建播放页（拿到 /play 结果之后还要等字幕） |
| `ParsePlaybackView.task` | 开始解析（解析更慢，还被字幕挡一下） |
| `VodDetailView.siteResource(...)` | 下一集 / 选集的换资源 |

改：新增 `AppModel.loadSubtitlesInBackground(sources:headers:)`（**同步**清掉上一集那份、下载丢后台），
三处全换过去。播放页观察的是 `model.subtitleCues`，下回来那份自己会上屏。

**顺带修掉一个顺序错误**：`SitePlayEpisodeView` / `ParsePlaybackView` 的 `onStart` 里原来有
`clearSubtitles()` / `clearPlaybackInfo()` —— 而这一集的字幕与「播放信息」是**进播放页之前**装好的，
`onStart` 一跑就把它们当场抹掉（改前就是这么串的：站点给的字幕/描述实际没上屏）。两处已去掉这两个清；
直链那条路（`VodDetailView`）没有「进页前预装」，清留下。

## 三、换集从头播（#2）

进度是**按片**记的（键 = 站点 + 影片），集下标在记录里；而 `resumableResource()` 原来只看键 ——
换集（选集 / 下一集 / 片尾连播）之后拿到的还是**上一集的记录**：位置照用（切过去直接跳到上一集
看到的地方）、片头片尾标记也照用（甚至被上一集的片尾标记当场带走）。

改：`PlaybackOpeningEndingRules.isSameEpisode(savedEpisodeIndex:currentEpisodeIndex:)`（纯函数 + 用例）——
**只有记录那一集 == 现在这一集才续播**，其余一律从头；`-1`（未知）不认。画面比例与集无关，照旧套用。

配套两处（不然会丢东西 / 误判）：

- `switchEpisode` 换集前 **`persist(force: true)`**：原先只在节流点落盘，换集会丢最后十几秒（这份位置
  属于旧的集下标，换了上下文再写就晚了）；
- `switchLine`（换线路 = 同一集）：按**新线路的集下标**把位置重记一次（两条线路的集下标常不同，
  不重记就会被判成换集、从头播）；`persist` 因此多了 `episodeIndexOverride`。

## 四、验证点

1. `swift test --package-path Packages/CatVodUI`：新增「只有记录那一集 == 现在这一集才续播」；
   `swift test --package-path Packages/CatVodSource`：新增 / 更新详情缓存挡板两条；
2. 上机：
   - 点封面 → 返回 → 再点同一个封面：应当**秒开**（第二次起走缓存）；
   - 点一集开播：不该再被「下字幕」卡住（有字幕的话，字幕晚一拍上屏即可）；
   - 看完一集自动下一集 / 选集里点另一集：应当**从头播**；回到上次那集（同一集）仍续播；
   - 换线路：同一集接着播（不回到 0）。
