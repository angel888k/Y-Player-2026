# M28P23 设置页：底部「赞助作者」（点开是赞赏码）

- 状态：**已改**（本地闸门全绿）；上机验证随下次构建
- 时间：2026-10-12
- 触发：用户口径「在设置页最后加上赞助作者，点开后是我的这个图片」（微信赞赏码）。

## 做法

- 图片入**两个 App 的资源目录**（设置页在共享包 CatVodUI，图要在主 bundle 里取）：
  `Apps/YPlayer-iOS/Assets.xcassets/SponsorQR.imageset/` 与 `Apps/YPlayer-macOS/...` 各一份
  （单倍图 1152×1152、约 104KB；`Contents.json` 为 single-scale，actool 直接编）。
  **不需要改 `project.yml`**：资源目录是整体参与构建的，往既有 `Assets.xcassets` 里加 imageset 即可。
- 设置页（`SettingsView`）在「版本 / TG 群组」之后加最后一行 **赞助作者** → `SponsorView`：
  一张赞赏码 + 一行说明（如实写「完全自愿，不打赏也不影响任何功能」）。
- 不做「跳转链接」：赞赏码本来就是图片（微信不给 URL），本地图最简、最稳，也不依赖网络。

## 验证点

- 本地闸门：花括号 / Lint / 重名 / 可见性 / SwiftFormat 全绿；`Scripts/check_app_icons.py` 两个
  资源目录都通过（新增 imageset 不影响 AppIcon 校验）；
- 上机：设置页拉到最底 → 「赞助作者」→ 页面显示赞赏码图片。
