## 二、第一批：TMDB 详情页（本次已改）

| 项 | 参考（截图 + 逆向） | 改法 |
|---|---|---|
| 头图 | 从顶部铺到约「一个屏宽」那么高，**底部化进页面底色**（不是压一条黑边） | `heroAspectRatio = 1:1`（按宽度定高，iPad / 横屏跟着长）；渐变改成往 `PlatformShims.pageBackground` 融 |

| 剧集 | **16:9 剧照网格**：卡基准 210×118、圆角 14、间距 6；列数按宽度算（`_columnsCount`） | `LazyVGrid` + `episodeGridColumnCount`：`clamp(⌊(W+6)/216⌋, 2, 5)`（手机 2 列、iPad 4~5 列） |
| 页面内边距 | 14 | 14（原 16） |
| 「更多」弹层 | 「剧集列表」+ 右上两个图标按钮（展开 / 收起、正序 / 倒序）+ **胶囊行**（当前集更亮） | `EpisodeListDrawer` 跟着改 |

## 三、第二批（待做，用户已给的参考里都标了位置）

   不再先落竖屏播放页；
2. **播放器控制条重排**（对齐 8 张全屏截图）：
   - 顶栏：左 = 关闭 / 投屏 / 旋转 / 画面比例；右 = 画中画 / 弹幕 / 画质 / 锁；
   - 底栏：上排 = 参数徽标（HW HDR H265 4K 25FPS 5.6Mbps）+ 当前时间 + 进度条 + 总时长；
     下排 = 左（播放 / 暂停 + 下一集）+ 右五个文字按钮「播放器 / 字幕 / 视轨 / 片头片尾 / 选集」；
   - 弹层形式：倍速（0.75–4.0）、弹幕（开 / 搜索 / 设置）、字幕（关闭 / 设置 / 导入 / 搜索）、
     视轨（带编码 / 分辨率 / 帧率）、片头片尾（片头 / 片尾 / 重置）—— 都是短列表弹出；
3. **待拍板**：投屏（DLNA/AirPlay）与画中画是我们项目**没有**的功能，做不做等一句话。
