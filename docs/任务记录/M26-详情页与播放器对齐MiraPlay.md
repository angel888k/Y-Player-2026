## 二、第一批：TMDB 详情页（本次已改）

| 项 | 参考（截图 + 逆向） | 改法 |
|---|---|---|
| 头图 | 从顶部铺到约「一个屏宽」那么高，**底部化进页面底色**（不是压一条黑边） | `heroAspectRatio = 1:1`（按宽度定高，iPad / 横屏跟着长）；渐变改成往 `PlatformShims.pageBackground` 融 |
| 标题 / 线路名 | 白色粗体 + 投影，线路名小字 | `.title.bold()` / `.subheadline` + `shadow` |
| 播放按钮 | 浅底深字（浅色外观下近白） | `Color.primary.opacity(0.07)` 底 + `.primary` 字 + 圆角 14 |
| 简介 | 默认两行，**点一下展开 / 收起**（`_synopsisExpanded`） | 2 行 + 点击切换；超 40 字才摆「展开」 |
| 剧集 | **16:9 剧照网格**：卡基准 210×118、圆角 14、间距 6；列数按宽度算（`_columnsCount`） | `LazyVGrid` + `episodeGridColumnCount`：`clamp(⌊(W+6)/216⌋, 2, 5)`（手机 2 列、iPad 4~5 列） |
| 页面内边距 | 14 | 14（原 16） |
| 「更多」弹层 | 「剧集列表」+ 右上两个图标按钮（展开 / 收起、正序 / 倒序）+ **胶囊行**（当前集更亮） | `EpisodeListDrawer` 跟着改 |

## 三、第二批：播放器（本次已改）

| 项 | 参考（截图） | 改法 |
|---|---|---|
| 点播放 | 「emby视图下点击播放直接全屏」 | TMDB 视图下点播放 / 点剧集卡 → `fullScreenCover`：**只有画面 + 叠层控制条**（没有导航栏、没有信息列表）；自动播放同样跟着走。非直链集（换地址 / 解析 / 不支持）在全屏里包一层导航容器 —— 那几张页面自带工具栏，卸掉会把人困住 |
| 顶排 | ✕ · 投屏 · 旋转 · 画面比例 —— 画中画 · 弹幕 · 画质 · 锁 | ✕（关播放）· 画面比例（只列内核真支持的档位）—— 弹幕（开关 / 搜索 / 设置）· 倍速（`SpeedSetting.presets`）· 锁 |
| 底排 | 参数徽标 + 时间 · 进度条 · 总时长；播放 / 暂停 · 下一集；「播放器 字幕 视轨 片头片尾 选集」 | 参数徽标（`HW HDR H265 4K 25FPS 5.6Mbps`，**由 `PlaybackStats` 现算**：硬/软解、HDR、编码、分辨率、帧率、码率，读不到的项不占位）+ 时间 / 进度条 / 总时长；播放 / 暂停 · 下一集 · 逐帧；文字按钮「字幕 / 音轨 / 片头片尾 / 选集」（都是短列表菜单） |
| 背景 | 图标直接压在画面上 | 上下两条渐变压暗（不糊整屏） |

**参考里有、我们没做的**（照「不摆假开关」的规矩不出现）：投屏（DLNA / AirPlay）、画中画、
「播放器」（内核切换 —— 我们在设置里换）、「视轨」（没有视频轨选择）、画质（滤镜）。
